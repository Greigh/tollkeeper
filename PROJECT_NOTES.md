# Tollkeeper — Project Notes

Quick reference for anyone working on this codebase.

## Project purpose

`tollkeeper` is a local-first application that routes coding tasks across AI subscriptions (Claude, Cursor, Gemini, Devin, Codex, Perplexity) and a metered fallback (OpenRouter). It chooses the cheapest capable adapter, preserves context across switches via capsules, and tracks spend in a local SQLite ledger.

Design constraints:
- Local-only state. No cloud, no shared credentials.
- Optional secrets: `OPENROUTER_API_KEY` (metered fallback) and `DEVIN_API_KEY` (Devin Enterprise quota API).
  Secrets can be set via environment variables or through the web UI; they are persisted to `~/.config/router/secrets.json` with 0600 permissions and loaded at startup.
- Core logic lives in importable `router.core` / `router.service`. UIs are thin clients.
- Python 3.11+.

make install

# Run all tests and frontend build
make test
make build

# Run application
make app

# Or run backend + frontend dev server together
make dev

# CLI shortcuts
make status

# Build distributable wheel + sdist

## Key implementation notes

- **Adapters** implement a `Protocol` (`is_available`, `probe_quota`, `health`, `models`, `estimate_cost_usd`, `run`).
- **Availability** checks both the CLI on PATH and common desktop app install locations (`.app` bundles on macOS, Program Files on Windows, `.desktop` entries on Linux). A desktop app is considered reachable, but the adapter still requires a CLI to execute tasks.
- **Quota state** is `ok | depleted | unknown`. Vendors rarely expose a numeric balance, so the system uses sentinel parsing + cached observations.
- **Devin quota:** the adapter reads local Devin credentials (CLI `~/.local/share/devin/credentials.toml` or Desktop app SQLite on macOS `~/Library/Application Support/Devin/User/globalStorage/state.vscdb`) and calls Devin Desktop's own `GetUserStatus` Connect endpoint (`server.codeium.com`) to get the real daily/weekly quota percentage shown in the app. Falls back to CLI/desktop availability tracking if no credentials are found.
- **Vendor-reported percentage**: if a CLI emits text like `42% remaining`, the adapter extracts and stores `remaining_percent`.
- **Routing**: sunk-cost-first. Healthy subscription adapters beat metered ones. A TOML routing table can override per task class.
- **Capsules** are JSON snapshots stored in `~/.local/share/router/capsules/`. They carry task, plan, code state, route, and a resume brief.
- **Spend ledger** is SQLite at `~/.local/share/router/ledger.db`. Override with `ROUTER_HOME`.
- **Daily metered cap**: `daily_cap_usd` in config (default $5).

## IDE / environment configuration

- Python interpreter: `.venv/bin/python`
- VSCode/Cursor workspace settings: `.vscode/settings.json`
